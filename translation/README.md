# Źródła tłumaczenia 1.0.0

`EN_PL_1.0.0.json` jest kompletnym eksportem 1677 aktualnych par EN→PL, zgodnym z zatwierdzoną bazą projektu i pakietem wydania. Zachowuje techniczne ID, oryginalny EN, PL, kolejność i kategorię. `Crytivo_Club_EN_PL.json` opisuje trzy dodatkowe napisy menu poza I2. `glossary.json` zawiera terminy i reguły kontekstowe; nie jest mechanizmem globalnych zamian.

Nie edytuj EN ani identyfikatorów. Po zmianie PL sprawdź znaczniki, placeholdery, jednostki i użycie w grze. Nazwy typu `Blocks/Apartments` są identyfikatorami, a nie tekstem do tłumaczenia. Udostępniony eksport zastępuje prywatną roboczą bazę SQLite; nie zawiera kosztów API ani dzienników żądań.
